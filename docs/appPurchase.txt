5) payment ka flow kya hoga 

    User clicks "Buy Pro Monthly"
            ↓
    Frontend shows payment UI (card/UPI form from gateway SDK)
            ↓
    User enters payment details
            ↓
    Gateway processes payment → returns success/failure
            ↓
    Backend receives confirmation (via webhook — see below)
            ↓
    Backend updates user's plan in database
            ↓
    User now sees Pro features unlocked
